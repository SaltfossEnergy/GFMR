# Core lifetime

The useful lifetime of the core is defined by the following condition:
{ .lead }

<div class="lifetime-criterion" markdown>

For any unit cell in the core and at any axial location within that unit cell, the cross-sectional average graphite fast fluence, for neutron energies above 0.1 MeV, reaches 2 × 10<sup>22</sup> n/cm<sup>2</sup>.

</div>
