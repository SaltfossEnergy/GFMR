## Intended use

The GFMR is intended as a reference problem for the modeling and simulation of molten salt reactors, capturing many of the essential physical phenomena relevant to graphite-moderated MSR systems.

It is designed to be software-agnostic and can be implemented using a single-physics approach or within a complex multiphysics framework.
